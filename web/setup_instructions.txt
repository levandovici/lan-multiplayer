QUICK SETUP INSTRUCTIONS

1. Copy .env.example to .env:
   cp .env.example .env

2. IMPORTANT: Edit .env and verify these settings for development:
   APP_ENV=development

3. Install dependencies:
   composer install

4. Import database:
   mysql -u root -p < database.sql

5. Start server:
   php -S localhost:8000

6. Visit: http://localhost:8000

TROUBLESHOOTING:
- For production deployment, change APP_ENV to production
